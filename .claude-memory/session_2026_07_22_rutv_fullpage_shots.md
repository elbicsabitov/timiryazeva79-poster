## Решения

- **«Тёмная» = Glass** (дефолт шоукейса — именно её редакция видела при открытии всех zip; Apple Dark — альтернативный стиль). «Белая» = Light. **Apple Dark снят про запас, НЕ отправлен** (просили две; лежит в deliverables — докинуть по первому слову).
- **Полный экран = fullpage** (вся главная сверху донизу): редакция комментирует всю страницу (14 правок в 602707 были по всем секциям), viewport-кроп — подмножество fullpage.
- **Отправка документами (`force_document=True`), не фото**: TG-фото ужимает до 2560px по длинной стороне → 7791px высоты стало бы нечитаемой кашей.
- Без подписи — канон чистого форварда. Порядок как в просьбе: light → dark.
