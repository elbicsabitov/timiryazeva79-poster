- **«Лесенка» у Эльбика = несовпадение ШВОВ сетки между рядами, НЕ право-краевая обрезка**; bleed каруселей за экран — желаемое поведение. При двусмысленной геометрии — переспрашивать интерпретацию ДО правки (он ответил мгновенно и спас от неверной поставки).

- Полупрозрачный border поверх градиента с border-radius визуально рвётся в углах → всегда inset box-shadow.
- Telethon-дамп Saved: писать в файл с PYTHONIOENCODING=utf-8 (cp1251-консоль падает); document-изображения (не photo) качать отдельно по ids.
