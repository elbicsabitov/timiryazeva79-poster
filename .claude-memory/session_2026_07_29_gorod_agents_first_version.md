## Грабли/уроки
1. **[data-page=home] — full-bleed (-40px)**: каждая секция обязана возвращать поля сама (max-width+clamp), иначе прилипает к краям.
2. **Reviewer-агент рулит ТЕМ ЖЕ браузером** (ресайзы/темы/роли/LS) — пока он работает, вкладка owner'а «прыгает»; мерить только в isolated-context вкладке.
3. **Роль переживает перезапуск браузера** (LS) — «заглушка слетела» = юзер залогинен, не баг гейта.
4. **applyHomeVariant/LS**: вариант живёт в localStorage → для сравнения версий нужен URL-параметр (`?home=`), не пишущий в LS, иначе две вкладки показывают одно.
5. **Фон-слои (.bg-cinema/.bg-warm) включаются по теме** — новая тема без opacity-правила остаётся с погашенным фоном; computed сразу после переключения ловит транзишн-кроссфейд (600ms).
6. Chrome-devtools `resize_page` применяется к SELECTED page — при нескольких вкладках сначала select_page, иначе ресайзишь чужую.
