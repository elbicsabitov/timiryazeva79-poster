## Правки и их судьба (все внесены, применены к v2.8.1)

1. **Меню −«Каналы»** → пункт удалён, страница/данные/рендер сняты целиком (не оставлять орфан: localStorage шарится между file://-страницами — сохранённый `route=channels` из старой версии гасится гардом `setRoute` → home; `channels` убран из `titles`).
2. **Эфир при навигации + перенос окошка** → PiP уже включался на любой странице (`route !== 'home'`); добавлен **drag в любой угол** («как в VK Видео»): pointer events (мышь+палец, `touch-action:none`), порог 8px отделяет клик от переноса, `setPointerCapture` в try/catch, магнит к ближайшему углу по центру окна (`data-corner="br|bl|tr|tl"`, во время переноса `data-dragging` глушит right/bottom через `!important`), FLIP-доводка 220ms (гейт prefers-reduced-motion — CSS-глушилка Web Animations не выключает), флаг `pipWasDragged` гасит клик-развёртку после отпускания. Крестик скрывает окошко БЕЗ остановки эфира + тост «вернуть можно с главной». Свайп-инерция реального плеера — при имплементации (RUTV-140).
3. **Телепрограмма на «Программах»** → секция над сеткой программ: пилюли Пн-Вс (сегодня подсвечен «· сегодня»), список слотов, «Сейчас» по реальным часам. ⚠️ **Ловушка «Сейчас»**: ночной слот 00:00 стоит В КОНЦЕ сетки → `0:00 ≤ now` истинно всегда → сканер «последний начавшийся» всегда выбирал ночной; фикс — последний слот исключён из сканера, он «сейчас» только до первого утреннего. Вечерний прайм собран из заявленных времён программ (Супер 20 Пт 19:00, Русский чарт Вт 19:00, Закулисье Ср 21:00, Звёзды Хайпа Сб 20:00, Караоке-батл Вс 18:00, Дискотека 2000-х Пт 22:00, Утро будни 07:00); «Новости в начале каждого часа» — строкой под сеткой. Сетка демо (RUTV-137).
4. **+«Контакты» в меню** → страница с пилюлями **Контакты | Выдача призов** рядом (аналог Monte Carlo): 4 карточки контактов (данные из подвала ДОСЛОВНО — антигаллюцинация) + призы (шаги получения, будни 12:00–18:00, паспорт, prizes@ru.tv) + CTA «К витрине подарков».
5. **Главная**: Новости ВЫШЕ Программ (swap) · подборки по годам (80-е/2000-е с LIVE-плитками) → отдельная вкладка **«Ностальгия»** (рабочее имя за редакцией, RUTV-139; id-контейнеры track80s/track2000s не менялись — рендеры работают как были) · «Новые клипы» с главной сняты (данные живут «Новинками» на странице Видео).
6. **Соцсети заметнее** → правая колонка у эфира стала `promo-col` (flex): рекламная панель (flex:1) + **панель-карточка VK / OK / MAX кругами**, нижняя кромка вровень с окном трансляции (grid stretch, edgeDiff 0 числом). Глифы типографикой — как полоса РМГ до официальных векторов (RUTV-138). В подвале ссылки ОСТАВЛЕНЫ («поднимите» ≠ «уберите снизу»). На мобиле промо-слот скрыт, соц-панель остаётся под эфиром во всю ширину.

## Верификация

- DOM-аудит числом: меню = Главная|Видео|Новости|Программы|Ностальгия|Артисты|Ведущие|Витрина подарков|Контакты|Премия; порядок главной = Промо → Свежие новости → Программы → Супер 20; упоминаний channels = 0; edgeDiff соц-панели с эфиром = 0; день-пилюль 7, «Ср · сегодня» верен; «Сейчас» = Закулисье при 21:21 (после фикса ночного слота).
