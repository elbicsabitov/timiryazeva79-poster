**Запрос Эльбика:** «аудит по UI, можешь менять стилистику, главное чтоб выглядело супер технологично и современно.»
**Грунд:** визуальный ресёрч `docs/research/gorod-fm/10-ux-visual-motion.md`.

## Главная находка (keystone) — ✅ исправлено

**Проблема:** дефолтный фон = насыщенный **cyan→blue градиент-«wash»** (`--bg-base: linear-gradient(-90deg, brand-cyan → brand-blue → brand-deep)`). Это ровно «slop-tell» из ресёрча (агрессивные multi-stop градиенты + saturated blue-black). Делает продукт «нарядным», а не технологичным.

**Фикс (commit этой сессии):** нейтральный near-black `#0B0C0F` + ОДИН сдержанный brand-glow сверху:
```css
--bg-base: radial-gradient(120% 82% at 50% -8%, rgba(81,104,252,0.12) 0%, rgba(81,104,252,0) 46%), #0B0C0F;
```
+ нейтрализован `--bg-overlay` (ink-purple → near-black). Эффект: весь апп читается как премиум-dark (Linear / Arc / Vercel), `#5168FC` — единственный акцент, **цвет несёт обложка** (tiles, артисты). Проверено: `#/taste`, `#/podborki`, `#/home`, `#/onboarding` — консистентно.

## Что уже работает на «технологично» (оставить)
- **Onest** везде (без Inter/Roboto/slop-шрифтов), fake-wide через scaleX.
- **Живая «волна»** (canvas) на `#/taste` = единый аудио-мотив-идентичность (ресёрч: ОДНА волна = всё).
- Тёмные glass-панели (чат, dials) с hairline-бордерами rgba(255,255,255,0.08–0.10).
- `#5168FC` tint-акцент на активных состояниях; tabular-nums на числах.
- Concentric-радиусы, focus-visible 3px, prefers-reduced-motion.

## Рекомендации (следующая полировка, низкий риск)
1. **Унифицировать акцент:** часть focus-ring/fill всё ещё на `--brand-cyan rgb(56,140,180)` → перевести на `#5168FC` (единый акцент).
2. **Аудио-реактив волны** через `AnalyserNode` когда появится реальный звук (сейчас CSS-breathing) — «волна реагирует на музыку» = signature-момент.
3. **Волна как фон now-playing** (не только `#/taste`): тонкая реактивная волна за мини-плеером.
4. **Микро-моушн:** Apple-style «дыхание» обложки, мягкие transition на смене трека (ресёрч: calm, не TikTok).
5. **Сетка/нойз-текстура** опц. — только если очень тонко (иначе slop). По умолчанию restraint > декор.
6. Ретемизация Warm/Light под нейтраль-доктрину (сейчас только Cinema нейтрализован).

## Anti-slop правила (зафиксировать как gate)
❌ агрессивные multi-stop градиент-фоны · ❌ декоративное свечение, реагирующее ни на что · ❌ orb-аватар для AI (только ambient/edge-aura) · ❌ >1 акцентный цвет. ✅ нейтраль-near-black + 1 акцент + цвет от контента.
