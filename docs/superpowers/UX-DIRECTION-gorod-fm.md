# Город ФМ — UX-направление: «AI присущий сайту» + next-gen платформа

**Синтез Karpathy-tier UI/UX ресёрча** (4 параллельных агента, 2026-06-02).
Источники: `docs/research/gorod-fm/07-ux-native-ai.md` · `08-ux-music-platform.md` · `09-ux-explainability-steering.md` · `10-ux-visual-motion.md`.
Триггер: «AI ощущается как прикрученный сбоку чат — сделай присущим сайту».

---

## Большая идея (одной строкой)

> **AI — это слой, а не окно.** Twinr живёт В плеере (как Spotify AI DJ), а не в углу. «Волна» (живая, аудио-реактивная) — это и есть главный экран, идентичность и сам Twinr.

Текущий угловой чат-док = **тот самый anti-pattern**. Не удаляем — **понижаем** до редкого глубокого пути (экскурсы, «собери сет», резюме→вкус). **80% AI переносим inline** на поверхности, куда юзер и так смотрит.

---

## 1. Информационная архитектура: 3 вкладки (бриф 08)

**Волна · Мой вкус (Twinr) · Открыть.** И всё.
- Убить отдельные Search / Radio / Browse-вкладки (Sonos отгрузил 3 дублирующие browse-вкладки из 5 → ~$500M провал). Поиск — в чат + одна affordance сверху.
- **«Волна» = главный экран** (не сетка плейлистов): полноэкранный art-tinted плеер + **живая волна, которая перестраивается при стиринге** в реальном времени. Это самый ownable премиум+explainable момент — ни один конкурент его не показывает.
- Деградация на каждой поверхности: плеер + skip + like + **voice-steer**. Voice-steer = нативное авто/ТВ взаимодействие.

## 2. AI inline — 5 ходов по приоритету (бриф 07)

1. **Always-on «почему?» reason-чип на now-playing** (3–6 слов, тап → раскрыть KG-path). Объяснение живёт НА треке, не в чате. **Высший рычаг** (+4× кликов у Spotify на объяснённых треках).
2. **Twinr steer-кнопка на карточке** (жест AI DJ: тап = «Встряхнуть»/re-roll, зажать = голос/текст-стир) + inline steer-чипы (Темнее / По-другому) + **Yandex-style mood/activity-диалы** — всё пишет в ОДИН session-intent вектор.
3. **Живой Twinr-виджет на главной** (видимый + редактируемый), который **анимируется, когда ты стиришь** где угодно.
4. **Между-трековая «now→next» лента** (текст по умолчанию, голос опц.), event-gated на **бюджет 3–5 прерываний/сессию** — нарратив на смене вайба/стире, НЕ каждый трек.
5. **Открывать чат-док ИЗ inline affordances** (Cmd-K «Спросить Twinr», @-mention контекста) — чтобы ощущалось непрерывно.

## 3. Объяснимость + стиринг + профиль (бриф 09)

Три **достижимых-из-плеера** поверхности, чат не нужен:
- **Why-чип, прогрессивное раскрытие:** L1 = одна причина на простом русском («Потому что вы слушали Молчат Дома») + ⓘ; L2 hovercard = реальный KG-path/attribute; L3 = полный тур.
- **Диалы + свободный текст, один общий session-вектор:** одна steer-кнопка AI DJ (тап=re-roll, зажать=голос/текст) + диалы Моя волна (компактные чипы) + per-track 👍 / «меньше такого». Диалы = ленивый путь, текст = точный. **Не должны конфликтовать.**
- **Twinr = first-class редактируемый экран + анимированный бейдж в плеере:** вектор как строки Жанры/Настроения/Артисты/Эпохи с +/−/pin/mute, timeline эпох + недельная дельта (Last.fm «живой»), shareable-карточка. Правки → durable профиль через confirmation-gate.
- **Seamful design:** дать юзеру **отвергнуть причину** → правка летит прямо в видимый профиль. (Tintarev & Masthoff: чип→transparency, диалы→control, редактор→scrutability.)

## 4. Визуал / motion / идентичность (бриф 10)

- **ОДНА аудио-реактивная «волна» = вся идентичность:** она же Twinr, логотип, лоадер, now-playing hero. Одна идея везде = премиум-целостность. НЕ стакать waveform+частицы+mesh+blob.
- **Twinr = ambient presence, НЕ orb-аватар.** Рынок (Siri, ChatGPT voice) ушёл от плавающего шара к **краевым аурам**. «Speaking»-состояние Twinr = волна отрывается в краевое свечение + подпись, потом сливается обратно.
- **Убить 2 признака slop:** агрессивные multi-stop градиенты и декоративное свечение, реагирующее ни на что. `#5168FC` — **единственный** акцент над нейтральным near-black (`#0B0C0F`, не насыщенный сине-чёрный); цвет даёт обложка.
- **Реактивность к реальному звуку:** `AnalyserNode` (`fftSize 2048`, `smoothing ~0.8`), один rAF-цикл, CSS-«дыхание» fallback на мобиле. Фейковые лупы = распыление.
- **Локальность через геометрию, не декор:** кошкар-муйiз (бараний рог) спираль = «бесконечность/непрерывность» в покоящейся кривой волны. Не лепить сакральный орнамент обоями.
- **4 signature-момента:** «Станция зажигается» · «Twinr говорит» · «Ты это сформировал» · «Кошкар-волна».
- Hard gates: `prefers-reduced-motion` + AA-контраст.
