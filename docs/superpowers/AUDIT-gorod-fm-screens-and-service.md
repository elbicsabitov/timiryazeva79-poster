## 0. TL;DR (прочитать первым)

**Главный вывод:** у прототипа ДВА класса экранов с пропастью в качестве.
- **AI-поверхности** (Волна `#/home`, Мой вкус `#/taste`, Онбординг) — несут wedge, сильные, on-thesis.
- **Legacy стриминг-экраны** (Подборки, Медиатека, Артист, Трек, Избранное) — «ещё одно музыкальное приложение»: красиво, но (а) НЕ объясняют/не рулят (0 wedge), (б) кишат slop-плейсхолдерами (градиент-обложки, силуэт-аватар артиста).

**Стратегический сдвиг:** wedge (объяснимость + управляемость + видимый редактируемый профиль) выражен сейчас ~на 30%. Задача аудита — выразить его на КАЖДОЙ поверхности, переделать legacy-экраны под AI-вижн, и сделать «Волну» best-in-class.

**North star (из синтеза):** *«Ты видишь свою логику и можешь её поправить — даже реклама твоя.»* Доверие строится не на красоте слов, а на **fidelity**: объяснение соответствует реальному вектору. Это единственное, что отделяет прозрачность от маркетинга — и единственное, что Яндекс/Spotify не скопируют быстро (у них профиль СКРЫТ умышленно).

**🔑 Конвергенция 6 агентов** (независимо сошлись → высший приоритет):
1. **Честная «почему»-строка под КАЖДЫМ треком** — назвали top-фичей 3 из 6 агентов (Волна, Habit, Explainability). Поведенческая, не маркетинговая: «ты дослушал 3 раза», НЕ «тебе понравится».
2. **«Исправь причину»** (seamful reject) — единственная механика, которой нет ни у кого. Steering ЧЕРЕЗ объяснение.
3. **Цвет-от-обложки** (Vibrant.js → перекраска now-playing) — самый высокий ROI премиальности.

## 2. Информационная архитектура — решение

**3 вкладки. Железное правило: «Открыть» = НЕИЗВЕСТНОЕ. Всё известное → «Мой вкус».** Смешивать архив и discovery — главная ошибка стриминговых приложений (discovery-агент).

```
ВОЛНА (#/home)        МОЙ ВКУС (#/taste)          ОТКРЫТЬ (#/discover)
= радио, пассив       = профиль + архив, актив-я   = неизведанное, актив-мир
• now-playing         • редактируемый вектор        • РАЗГОВОР (семант. запрос)
• «почему» + steer    • Twinr-recap (неделя)        • КАРТА ВКУСА (кластеры)
• контекст-карусель   • Сохранённое (быв.Избранное) • редакторский ряд (быв.Подборки)
• between-track       • Медиатека (архив)           • «рядом с твоим вкусом»
                      • shareable-карточка
```

- **Артист / Трек** = deep-dive, открываются из ЛЮБОЙ карточки трека (не пункты навигации). Артист: + «почему тебе этот артист» вверху. Трек: главный explainability-экран (полное «почему» + вектор + соседние треки по атрибутам).
- **Подборки** убить как раздел → один горизонтальный «от редакции» ряд внутри «Открыть».
- **Поиск** = иконка-лупа (не таб) → семантический («осенний дождь за окном» → треки по настроению).

## 3. «Волна» — целевой дизайн главного экрана

Занять щель между Яндексом («контекст ДО запуска» но без per-track «почему») и Spotify DJ (лучший steering, но изолированный режим): **контекст выбирается ДО · reason виден ВО ВРЕМЯ · стир одним тапом — всё на одном экране, без переключения режимов.**

```
┌──────────────────────────────┐
│  CONTEXT CARD  (~30%)        │  карусель сценариев при старте →
│  «Спокойное для концентрации»│  схлопывается в чип + «Сменить»
├──────────────────────────────┤
│   ARTWORK / WAVE (~40%)      │  fullbleed ФОТО АРТИСТА (не абстракт-обложка);
│   [Artist Photo]             │  audio-reactive волна = ambient СЛОЙ снизу,
│   ~~~~ wave ~~~~             │  НЕ перекрывает лицо, НЕ главный визуал
├──────────────────────────────┤
│  TWINR «ПОЧЕМУ» (~8%)        │  1 строка, 4-6 слов, поведенческая.
│  «Тempo как ты любишь утром» │  тап → раскрыть L2-карточку (§4)
├──────────────────────────────┤
│  CONTROLS (~22%)             │  ❤  [—TRACK—]  ✕   + [Стир]
│  Стир → bottom-sheet 3 опции │  («Больше такого» / «Убрать артиста» / «Сменить настроение»=текст)
└──────────────────────────────┘
```

- **Between-tracks:** НЕ пустой плеер/спиннер → **transition card** (размытый artwork следующего + имя + его «почему»), 1.5-2с = «DJ объявляет следующий трек» без аудио. Буфер >3с → волна + «Загружаю…».
- **Desktop:** 2 колонки — слева artwork+волна, справа Twinr-профиль + история сессии (3-5 прошлых треков с reasons). Клавиши: пробел=пауза, →=стир, ←=лайк.
- **Авто/голос:** 3 команды — «Больше такого» / «Поменяй» / «Почему этот трек» (TTS отвечает reason-строкой).
- **Anti-pattern:** skip-oriented UI (если скип — самый заметный контрол, юзер скипает). Лайк и стир первичны, скип доступен но вторичен.

## 4. Wedge, углублённый — Explainability + Steering (категорийно-определяющее)

**Главная ошибка конкурентов:** confounding justification с transparency. Spotify DJ объясняет красиво, но нарратив НЕ связан с реальным вектором = «perceived transparency». Юзер проверит → потеряет доверие навсегда (Hacker News-паттерн).

### Прогрессивное раскрытие — 3 уровня
- **L1 — чип (≤5 слов), поведенческий/атрибутивный:** `[Похожа на Земфиру]` `[3× дослушал до конца]` `[Под утро]`. НЕ «тебе понравится».
- **L2 — hovercard/tap (3-5 строк) + кнопка «Исправь причину»:**
  ```
  Почему играет сейчас:
  • Tempo 112 BPM — твой утренний ритм
  • Женский вокал + акустика — паттерн, 7× дослушал за месяц
  • Настроение меланхоличное → ты выбрал «Спокойно»
  [Исправить причину]  [Закрыть]
  ```
- **L3 — тур профиля** (при онбординге + по запросу): как каждое действие влияет на вектор. Визуально, не словами.

### Правило честного сигнала (что делает доверие, не фантик)
Каждое объяснение ссылается на РЕАЛЬНОЕ действие юзера или измеримый аудио-атрибут. **Запрещено:** «Специально для тебя», «Тебе должно понравиться», «Похоже на то, что слушают люди как ты» (collaborative без конкретики = жутко). Честные шаблоны (RU):
```
«Ты дослушал «[трек]» 4 раза — жанр важен»
«BPM как ты слушаешь по пятницам вечером»
«Поставил 👍 двум трекам с похожей гитарой»
«Настроение "Активно" → темп 120+»
```
Тон: нейтрально-информативный в объяснениях; эмоциональный — только в DJ-комментарии между треками (пожилая аудитория РФ негативит на игривый тон в объяснениях).

### Steering — 4 канала в ОДИН вектор + видимая квитанция
| Канал | Юзкейс | Механизм |
|---|---|---|
| Диалы mood/activity | ленивый сдвиг | session-вектор, ближайшие ~10 треков |
| Текст/голос | точный запрос | LLM→attribute delta (session/permanent) |
| Per-track 👍/«меньше» | реактивный | +/- атрибут трека в профиль |
| **«Исправь причину» (L2)** | **seamful контроль** | **reject основания → выпадает из формулы, Волна пересчёт live** |

**Видимый эффект ОБЯЗАТЕЛЕН:** после любого steering — микро-анимация изменения «Мой вкус» + квитанция («Добавлено: меньше [genre]. Волна обновляется»). Без квитанции юзер через 2-3 попытки считает систему сломанной (CHI 2025: мотивация рулить определяется ВИДИМОСТЬЮ эффекта, не точностью).

## 5. Визуал / Motion / Identity — дизайн-система

**Принцип:** премиум-2026 = не эффекты, а «каждый пиксель знает зачем он здесь». Главная опасность — перепутать «живость» с «анимированностью».

### Токены (фрагмент — полный набор в ресёрче)
```css
--color-base:#0B0C0F; --color-surface-1:#111318; --color-surface-2:#191C24;
--color-accent:#5168FC;  /* ЕДИНСТВЕННЫЙ */  --color-hairline:rgba(255,255,255,.08);
/* DYNAMIC (JS при смене трека, из обложки через Vibrant.js + OKLCH-контраст-гейт) */
--color-art-vibrant; --color-art-bg-start; --color-art-bg-end;
--radius: 4/8/12/20/full;  --dur: 80/160/280/500ms;
--ease-standard:cubic-bezier(.4,0,.2,1);
```

### 5 signature-моментов (одна волна-идентичность сквозь поверхности)
1. **Лоадер** = только волна (FFT, 8 баров), без «загрузка».
2. **Онбординг** = волна растёт с каждым выбором (амплитуда scaleY 0.2→1.0).
3. **Now-playing** = фон перекрашен из обложки (Vibrant.js DarkVibrant), волна — единственная анимация.
4. **Twinr говорит** = НЕ орб → краевое свечение карточки (box-shadow blur, «дыхание» sin(t)/1.6s), гаснет когда молчит.
5. **Смена трека** = cross-fade фона 400ms + обложка scale(.96→1). Без слайда (у музыки нет направления).

### Anti-slop чек-лист (чинит наши текущие нарушения)
❌ >1 акцент (purple+teal+pink = «AI palette») · ❌ gradient-mesh/aurora фон не от трека · ❌ орб-аватар с shimmer (это 2023) · ❌ SVG-иллюстрации/градиент-плейсхолдеры вместо реал-контента (← наши Трек/Медиатека/Артист!) · ❌ glassmorphism без семантики · ❌ fake-волна из @keyframes (она врёт — только FFT) · ❌ тени без цвета (Bootstrap-вид) · ❌ эмодзи-как-иконки-навигации.

## 6. Онбординг + Habit/Retention (ежедневная привычка)

**Уникальный актив, которого нет ни у кого: прозрачная модель.** Вся habit-loop вокруг этого: «ты видишь как тебя понимают, и это меняется каждый день». Стрики/recap = не хуки, а *доказательства роста*.

- **Cold-start «Первая волна за 45с»:** + импорт-seed (Last.fm/Apple/история → «нашли твой вкус за 3с» WOW) · темп-калибратор после 3 треков · **показать модель после 7 треков** + кнопка правки (ключевой wedge-момент).
- **Ежедневно:** «Утренняя волна» (7-10 утра, своя обложка, «85 BPM, 40 мин, начать мягко», пуш 7:45) · контекстные старты «Утро/Работа/Вечер» (меняют BPM/энергию).
- **Еженедельно:** **Twinr-recap** (вс 19:00) — «+darkwave, −арена-рок», 1 неожиданное открытие с «почему». **Shareable-карточка 9:16** = радар жанров + слово-идентичность («Меланхолия с синтезатором»), НЕ числа как Wrapped → виральность бесплатно.
- **Стрики «Дней с Волной»** 1→7 (не 30), loss-aversion, + «заморозка» 1/мес (без неё пропуск убивает привычку навсегда — урок Duolingo).
- **Re-engagement:** «Волна скучает» (3 дня без сессии, anthropomorphic loss) · «твой артист выпустил» (event-пуш, ≤10 слов).
- **Anti-dark-pattern:** не делать Wrapped еженедельно (убивает эксклюзив) · send-time optimization (2 релевантных пуша/нед > 7 «полезных») · никаких бейджей-«100 треков» (метрика платформы, не опыт юзера).

## 7. Архитектура / Монетизация / Moat

**Moat строится не из UI, а из данных:**
- **`reason_tag` corpus** = главный ров. Каждый skip/like/текст/«исправь причину» → `(track_id, reason_tag, session_vector)` в лог → labeled pairs для дообучения retrieval. Через 6 мес — датасет ОБЪЯСНЁННЫХ предпочтений, которого нет ни у Spotify, ни у Яндекса. **Нельзя купить ретроспективно — у них нет интерфейса для сбора.**
- **Twinr-профиль = cross-product identity:** slow EMA (ночь) + fast SASRec (30с) + explicit edits (<50ms CTRL-Rec). Связка с рекламным кабинетом Twinr/Большой Цифровой: рекламодатель покупает `taste_segment: post-punk_melancholic + urban-engagement` (first-party, без PII) вместо «демо 25-35 Москва».

**Монетизация (RF/СНГ):** ad-tier первичен (taste-targeted audio CPM $8-15 vs $2-4 non-targeted) → premium через 6-12 мес (ключевая фича = «живой профиль», не музыка) → B2B taste-ads через кабинет (margin >60%). **Честное измерение:** Contextual Completion Rate (taste-match vs non-match) + показывать рекламодателю confidence-score рядом (не прятать).

**Лицензирование (без экзистенц-риска):** Стадия 0 демо = CC (Jamendo/FMA/ccMixter) → Стадия 1 seed = **MERLIN** (15% мирового рынка инди одним договором, ~$0.003-0.005/stream) + 2-3 куратор-лейбла РФ → Стадия 2 после PMF = мажоры. **НЕ запускать на мажор-каталоге без лицензии** (Suno/Udio → иски с позиции слабости).

**Wedge-защита (что не скопируют быстро):** видимый редактируемый профиль (ломает их позиционирование) · reason_tag corpus · cross-product identity (им нужна перестройка бизнес-модели) · RF/СНГ category-ownership.

## 8. Приоритизированный план (новые GOROD-задачи)

### P0 — Quick wins (конвергентные, высокий ROI, низкий эффорт) — делать первыми
- **GOROD-040** Честная **«почему»-строка под каждым треком** в Волне (поведенческая: «дослушал 3×», не «понравится»). 3/6 агентов = top-фича. ~1 день.
- **GOROD-041** **«Исправь причину»** на L2-hovercard (seamful reject → атрибут выпадает, волна пересчёт). Уникальная механика рынка. ~2 дня.
- **GOROD-042** **Цвет-от-обложки** (Vibrant.js → перекраска now-playing фона + OKLCH-контраст-гейт). Самый высокий ROI премиальности. ~3-4ч.
- **GOROD-043** **Убить slop-плейсхолдеры:** градиент-обложки (Трек/Медиатека/Избранное) + силуэт-аватар (Артист) → реал-ассеты из `assets/gorod-fm/` или цвет-от-контента. ~1 день.
- **GOROD-044** Behavioral-anchoring copy-pass: заменить все «тебе понравится» → история действий (чистый copy, 0 eng).

### P1 — Rework экранов (структурный wedge)
- **GOROD-045** Волна → 3-зонный layout (context-карусель / artwork+ambient-волна / «почему» / ❤✕Стир) + bottom-sheet стир. (§3)
- **GOROD-046** IA-реорг: «Открыть» = разговор + карта-вкуса + редакторский ряд; впитать Медиатеку+Избранное («Сохранённое») в «Мой вкус». (§2)
- **GOROD-047** Артист/Трек → deep-dive из карточек + «почему тебе» + (Трек) вектор/соседи. (§2,§4)
- **GOROD-048** Between-track transition card («DJ объявляет следующий»). (§3)
- **GOROD-049** Twinr edge-glow вместо орба + motion-токен-файл + prefers-reduced-motion pass. (§5)

### P2 — Loops/identity
- **GOROD-050** Weekly Twinr-recap + shareable-карточка 9:16 (радар + слово-идентичность). (§6)
- **GOROD-051** Контекстные старты «Утро/Работа/Вечер» на Волне. (§6)
- **GOROD-052** «Открытый профиль» demo-экран (для питча — убивает «Яндекс делает то же»). (§7 QW)
- **GOROD-053** Стрики «Дней с Волной» 1-7 + заморозка. (§6)
